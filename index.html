Conspectus is a free and open-source word processor controlled using vim motions. Documents are stored in plaintext and saved on your account for later access. You can export to PDF or download the unformatted plaintext file to your device.

About

Conspectus is a free and open-source project made by ←me! I decided to try making a word processor because I wanted to make a website that gave some sort of output. It uses an implementation of vim motions, although it is incomplete because I'm lazy and it would be too complicated.

Why vim motions?

Partly because it makes things easier since I wouldn't have to worry about the mouse, but also because I just really like vim motions. Being able to do everything on the keyboard without having to go to and from your mouse is really nice, especially if you have an ergonomic keyboard setup.

What is that logo?

I took the compass from the national emblem of East Germany, rotated it 90° counterclockwise, then mirrored it vertically. The font is Aporetic Sans colored #faf4ed with a stroke width of 0.5. The font color comes from the Rosé Pine color scheme, which is also the website color scheme.

Vim Cheat Sheet
h - move cursor left
j - move cursor down
k - move cursor up
l - move cursor right
w - jump forwards to the start of a word
e - jump forwards to the end of a word
b - jump backwards to the start of a word
^ - jump to the start of the line
$ - jump to the end of the line
i - insert before the cursor
a - insert after the cursor
o - append a new line below the current line
O - append a new line above the current line
Esc - exit insert mode
u - undo
Ctrl + r - redo
dd - delete a line
Ctrl + b - toggle bold text
Ctrl + i - toggle italicized text
